# ValutaTrade Hub

CLI-приложение для управления валютным портфелем. Позволяет регистрировать пользователей, покупать и продавать валюты, просматривать состояние портфеля и получать актуальные курсы фиатных и криптовалют.

## Возможности

- Регистрация и авторизация пользователей
- Управление валютными кошельками
- Покупка и продажа валют
- Просмотр портфеля с пересчётом стоимости в выбранную базовую валюту
- Получение прямого и обратного курса валют
- Автоматическое обновление курсов через внешние API
- Хранение истории обновлений курсов
- Логирование пользовательских операций

## Требования

- Python 3.12 или выше
- [uv](https://docs.astral.sh/uv/)

Основные зависимости устанавливаются автоматически:
- requests
- python-dotenv
- prettytable
- prompt

Для проверки качества кода используется Ruff.

## Установка

Клонируйте репозиторий и перейдите в каталог проекта.

Установите зависимости:

```bash
uv sync
```

## Настройка API-ключа

Для получения курсов фиатных валют используется ExchangeRate-API, для криптовалют - CoinGecko.

Создайте файл `.env` в корне проекта:

```env
EXCHANGERATE_API_KEY=your_api_key
```

Вместо `your_api_key` укажите собственный ключ ExchangeRate-API.

## Запуск

Запуск CLI:

```bash
uv run python main.py
```

Запуск автоматического обновления курсов:

```bash
uv run python main.py scheduler
```

## Команды CLI

Все команды выполняются в интерактивном режиме после запуска приложения.

### 1. Регистрация пользователя

Создание нового пользователя:

```text
register --username alice --password 1234
```

Имя пользователя должно быть уникальным, длина пароля — не менее 4 символов.

### 2. Авторизация

Вход в существующую учётную запись:

```text
login --username alice --password 1234
```

### 3. Просмотр портфеля

Просмотр кошельков и общей стоимости портфеля в USD:

```text
show-portfolio
```

Выбор другой базовой валюты:

```text
show-portfolio --base EUR
```

### 4. Покупка валюты

Покупка указанного количества валюты:

```text
buy --currency BTC --amount 0.05
```

Если кошелёк для валюты ещё не создан, он создаётся автоматически.

### 5. Продажа валюты

Продажа указанного количества валюты:

```text
sell --currency BTC --amount 0.01
```

Для продажи необходимо иметь кошелёк с достаточным балансом.

### 6. Получение курса валют

Получение курса из одной валюты в другую:

```text
get-rate --from EUR --to USD
```

Команда выводит прямой и обратный курсы, а также время последнего обновления.

### 7. Обновление курсов

Принудительное обновление курсов из внешних API:

```text
update-rates
```

### 8. Просмотр сохранённых курсов

Вывод актуальных курсов из локального хранилища:

```text
show-rates
```

## Parser Service

Parser Service получает курсы из двух внешних источников:

- **CoinGecko** - курсы криптовалют BTC и ETH к USD;
- **ExchangeRate-API** - курсы фиатных валют EUR и RUB к USD.

Обновление выполняется с учётом таймаутов и обработки ошибок API. Если один источник недоступен, приложение может сохранить данные, полученные от другого источника.

Для периодического обновления можно запустить Scheduler:

```bash
uv run python main.py scheduler
```

Он выполняет обновление сразу после запуска, а затем повторяет его с интервалом 300 секунд. Для остановки нажмите `Ctrl+C`.

## Логирование

Действия пользователей записываются в файл:

```text
logs/actions.log
```

Используется ротация логов: максимальный размер файла - 5 МБ, количество резервных файлов - 3.

Логируются основные операции, включая регистрацию, авторизацию, покупку и продажу валют.
